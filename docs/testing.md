## 자동 테스트와 한계

| 명령 | 검증 범위 | 별도 준비 |
| --- | --- | --- |
| `npm test` | 순수 날짜/집계 함수, jsdom React 화면, 데이터 접근 요청 구성·재시도·캐시·인증 | npm 의존성 설치 |
| `npm run lint` | ESLint 및 React 관련 정적 검사 | npm 의존성 설치 |
| `npm run build` | TypeScript 검사 및 Vite 프로덕션 빌드 | 웹 앱 환경 변수는 실제 화면 사용에 필요 |
| `npm run test:rules` | todos·studyLogs·interviewQuestions·applications 및 이월 규칙의 허용/거부 | Java 21 이상, Firebase CLI/에뮬레이터 다운로드·실행 환경 |

일반 테스트의 Firebase·REST 발송/조회는 주로 테스트 대역을 사용합니다. 실제 Firebase 연결·메일 수신·운영 인덱스·배포·스크린 리더·모바일 레이아웃 검증을 대신하지 않습니다. 테스트 수는 바뀔 수 있으므로 실행 결과의 pass·fail·skipped를 확인합니다.

```powershell
npm test
npm run lint
npm run build
```

## Firestore 규칙 에뮬레이터

```powershell
java -version
npm run test:rules
```

package.json은 demo-upday 프로젝트로 Firestore emulators:exec를 실행하고 네 개 규칙 파일을 순차 검증합니다. 운영 데이터에 연결하는 명령이 아닙니다. Java나 도구 다운로드가 불가능하면 실행하지 못한 것으로 기록하고 통과했다고 표시하지 않습니다.

일반 `npm test`에서는 FIRESTORE_EMULATOR_HOST가 없으면 규칙 전용 테스트를 건너뜁니다. 에뮬레이터 테스트를 실행한 것과 대상 운영 프로젝트에 규칙을 적용한 것은 별개입니다. 에뮬레이터는 운영 복합 인덱스 준비 여부를 보장하지 않습니다.

## 실제 계정 수동 확인

규칙을 적용한 테스트 프로젝트 또는 의도한 대상에서 계정 A·B와 비로그인 상태를 사용합니다. 각 작업 후 새로고침하여 저장 결과를 확인합니다.

### 인증·공통

- 이메일 로그인·로그아웃, 인증 로딩/오류와 재시도
- 비로그인 보호 경로 차단 및 로그인 상태의 로그인·회원가입 진입 시 대시보드 이동
- 회원가입 계정 생성 후 이름 저장 실패·로그아웃 실패 재시도 화면 유지
- 마이페이지 이름 수정·취소·오류 재시도, 대시보드 인사말 갱신
- 계정 전환 후 이전 사용자 입력·기록·통계가 남지 않는지 확인
- 새로고침·탭 닫기 경고는 사용자 상호작용 등 브라우저 정책에 따라 실제 표시 확인
- 키보드 초점·모달 복귀·날짜 입력 라벨·좁은 화면 줄바꿈 확인
- 비밀번호 재설정은 운영 문서의 실제 메일 확인 절차 수행

### Today

- 등록·수정·완료·취소·삭제, 빈 목록 0%, 완료/삭제 후 진행률
- 저장 실패 시 입력 유지 및 동일 ID 재시도, 실제 저장과 목록 갱신 실패 구분
- 과거 날짜 조회·이월 영수증 실패 상태·새로고침 복구
- 미완료 선택 이월·원본 보존·삭제 후 같은 날 재이월 제한
- 자정·탭 복귀의 오늘 갱신과 과거 기록 보존
- Study의 동일 날짜 합계와 일치, 기록 없는 날 0분·조회 실패 오류 구분

### Study

- 등록·수정·삭제와 createdAt 보존, 학습일·태그·시간 검증
- 날짜/태그 교집합, 필터 해제, 학습일·생성 시각·ID 순서와 더 보기
- 날짜 없는 기존 기록과 신규 기록 혼합 시 목록 차단·누락 없이 20개씩 표시, 보완 후 일반 조회 전환
- 날짜 보완 dry run·기존 날짜 보존·부분 실패 재실행·잘못된 날짜 및 응답 오류 검출
- 상세/수정 단건 조회와 없는 기록·권한 오류
- 잔디 기간·연도 변경, 연속 학습일의 오늘/어제 기준
- 주간 월요일~일요일, 월간 현재 월 오늘까지·과거 월 말일까지 집계
- 같은 날 여러 기록의 시간·개수 합산과 학습일 중복 제거
- 목록 필터와 통계 독립성, 월 이동 시 추가 메타데이터 조회 없음
- 60초 내 탭 복귀 캐시 적중, 만료 후 재조회, 수동 강제 새로고침
- 생성·수정·삭제 후 무효화, 계정 전환·늦은 응답·오류 재시도
- 전체 새로고침·문서 이동 시 메모리 캐시 초기화

### Interview·Job·대시보드

- Interview 질문·선택 답변·태그 CRUD와 상태 변경·복습 완료·생성 시각 보존
- 설명 가능 제외, 미복습·정확히 7일째·최근/미래 복습일과 필터 조합
- 20개 초과 질문·생성 시각 동률·더 보기 실패 재시도·삭제된 문서 건너뛰기
- 전체·조건 일치·현재 표시 개수 구분, 복습·수정 후 목록 복귀 갱신
- Job 등록·수정·삭제·상태 필터, 잘못된 URL·지원일·상태 거부
- Dashboard 복습 대상 수가 Interview 필터와 일치
- Job 지원 수의 관심·지원 예정 제외 및 현재 서류·면접 수 일치
- 카드별 로딩·오류·재시도, 실패를 0으로 표시하지 않는지 확인

### 계정 간 접근과 필드 검증

- B와 비로그인 사용자가 A의 기록을 읽기·수정·삭제하지 못하는지 확인
- 다른 UID 생성, 소유자·최초 생성 시각 변경 거부
- 빈 필수 값·길이 초과·잘못된 타입·추가 필드·중복 태그·잘못된 상태 거부
- Study 잘못된 학습일·날짜 필드 제거 거부 및 기존 문서의 날짜 추가 허용
- Interview 임의 복습 시각 거부 및 서버 시각 저장 허용
- Today 새 할 일/영수증의 원자적 이월 및 영구 영수증 제한 확인

자동·에뮬레이터·수동 결과와 미실행 항목을 PR에 구분해서 기록합니다.
